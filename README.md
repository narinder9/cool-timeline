## Overview

Cool Timeline is a powerful WordPress plugin that helps you create beautiful, interactive timelines for your website. Whether you want to showcase your company's history, product roadmaps, personal stories, or key events, this plugin provides the tools you need with both vertical and horizontal layouts.

### Key Benefits

- **Easy to Use**: Create timelines using Gutenberg blocks or simple shortcodes
- **Responsive Design**: Works perfectly on all devices and screen sizes
- **Multiple Layouts**: Choose from vertical, horizontal, and compact timeline designs
- **Highly Customizable**: Extensive styling options to match your brand
- **Page Builder Compatible**: Works with Gutenberg, Elementor, Divi, and other page builders

## Installation

### Method 1: WordPress Admin Panel (Recommended)

1. Log in to your WordPress admin panel
2. Navigate to **Plugins > Add New**
3. Search for "Cool Timeline"
4. Click **Install Now** next to "Cool Timeline"
5. Click **Activate** to enable the plugin

### Method 2: Manual Installation

1. Download the plugin from [WordPress.org](https://wordpress.org/plugins/cool-timeline/)
2. Extract the ZIP file
3. Upload the `cool-timeline` folder to `/wp-content/plugins/`
4. Activate the plugin through the **Plugins** menu

### Method 3: FTP Upload

1. Download and extract the plugin files
2. Upload the `cool-timeline` folder to `/wp-content/plugins/` via FTP
3. Activate the plugin in WordPress admin

## Quick Start

### Creating Your First Timeline

1. **Install & Activate** the Cool Timeline plugin
2. **Add Timeline Stories**:
   - Go to **Timeline > Add New Story**
   - Set a title and description
   - Choose a date for your story
   - Add an image (optional)
   - Publish the story
3. **Display the Timeline**:
   - Use the Gutenberg block: Add a new block and search for "Timeline"
   - Or use shortcode: `[cool-timeline]`

### Using Gutenberg Blocks

1. Create a new post or page
2. Add a new block and search for "Timeline"
3. Select the "Cool Timeline" block
4. Configure your timeline settings
5. Publish your content

## Usage

### Creating Timeline Stories

Timeline stories are created as custom post types. Each story represents an event or milestone in your timeline.

**Story Fields:**
- **Title**: The main heading for your timeline event
- **Description**: Detailed content about the event
- **Date**: When the event occurred
- **Image**: Visual representation (optional)
- **Icon**: Custom icon for the timeline marker (optional)

### Timeline Layouts

#### Vertical Timeline (Default)
```
Event 1
  ↓
Event 2
  ↓
Event 3
```

#### Horizontal Timeline
```
Event 1 → Event 2 → Event 3
```

#### Compact Timeline
A condensed version for displaying many events efficiently.

## Shortcodes

### Basic Shortcode

```php
[cool-timeline]
```

### Advanced Shortcode with Options

```php
[cool-timeline layout="default" skin="default" date-format="F j" icons="YES" show-posts="20" order="DESC" story-content="full"]
```

### Shortcode Parameters

| Parameter | Description | Default | Options |
|-----------|-------------|---------|---------|
| `layout` | Timeline layout type | `default` | `default`, `horizontal`, `compact` |
| `skin` | Visual theme | `default` | `default`, `modern`, `elegant` |
| `date-format` | Date display format | `F j` | WordPress date format |
| `icons` | Show timeline icons | `YES` | `YES`, `NO` |
| `show-posts` | Number of stories to display | `20` | Any number |
| `order` | Story ordering | `DESC` | `ASC`, `DESC` |
| `story-content` | Content display type | `full` | `full`, `excerpt` |

    padding: 20px;
